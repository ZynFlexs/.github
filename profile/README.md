## Who we are

ZynkreaTech is an independent software organization focused on building **ZynFlexs**, a modular Software-as-a-Service (SaaS) platform. We design software the way an ERP does — clean, modular, and built to grow with the business using it — while keeping it lightweight enough to run on the web or as a native desktop app.

## What is ZynFlexs?

ZynFlexs is a **multi-tenant, modular SaaS platform**. Instead of shipping one rigid application, ZynFlexs rents out individual business modules — CRM, billing, licensing, and more — to companies ("tenants"), letting each tenant install only what they need and switch it off just as easily.

- **Modular by design** — every feature is a self-contained module that can be installed or uninstalled without downtime.
- **Multi-tenant, isolated by database** — each tenant's data lives in its own dedicated database, not just a shared table with a tenant column.
- **Web-first, desktop-ready** — the same core application runs in the browser and as a native desktop app, sharing one codebase.
- **Online / offline aware** — designed to keep working when connectivity drops, syncing back up once it's restored.
- **Familiar, professional UI** — visually inspired by enterprise ERP tools, so business users feel at home from day one.

## Our approach

- **Documentation-first.** Every architectural decision is written down and versioned before (or alongside) the code that implements it.
- **Semantic Versioning 2.0.0** across every package, module, and service — independently versioned, predictably released.
- **Performance-minded.** Framework choices and code review both weigh runtime and developer-experience performance as a first-class concern, not an afterthought.
- **Security by isolation.** Tenant data isolation is enforced at the database level, not just the application level.

## Products & components

| Component | What it does |
|---|---|
| **ZynFlexs** | The core web application — the SaaS platform tenants use day to day. |
| **ZynFlexs Desktop** | A native desktop companion, sharing the same modules and packages as the web app. |
| **ZynFlexs Backend** | The API and services layer powering tenant management, billing, licensing, and sync. |
| **Centralized Tenant Management** | The "landlord" system — onboards tenants, manages subscriptions, licensing, and billing. |
